One-time setup on this device

Connect to GitHub

Your site lives on GitHub, so saving changes needs a GitHub access key. You make it once per device. It's stored only in this browser.

  1. Open GitHub → New fine-grained token (sign in as finkalink).
  2. Name it BEN F studio and pick an expiration (1 year is fine).
  3. Under Repository access choose Only select repositories → benf-ceramics and benf-records (your private archive).
  4. Under Permissions → Repository permissions set Contents to Read and write. Optional: Pages → Read-only (shows when the site is live).
  5. Click Generate token, copy it, and paste it below.
